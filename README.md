# AI 스마트홈 GitHub Pages v4 (모바일 최적화)

이 버전은 v3의 PC 디자인과 콘텐츠를 유지하면서 모바일 화면의 긴 세로 스크롤을 줄이도록 개선했습니다.

## 모바일에서 가로 스와이프로 전환되는 영역
- 실증 핵심 정보
- 연구기관
- 실증 협조기관
- 우리 집에는 무엇을 설치하나요?
- AI 스마트홈은 어떻게 작동하나요?
- 실증은 어떻게 진행되나요?
- 데이터 수집·사용 항목

FAQ는 기존처럼 아코디언 방식으로 유지합니다.

## GitHub Pages 업데이트
현재 v3를 사용 중이라면 `index.html`, `style.css`, `script.js`를 이 버전으로 교체하세요.
`assets` 폴더의 이미지 파일은 동일하므로 기존 assets가 정상적으로 올라가 있다면 다시 업로드할 필요는 없습니다.

브라우저 캐시 때문에 변경이 바로 안 보이면 Windows 기준 `Ctrl + F5`로 강력 새로고침하세요.
