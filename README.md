# AI-SmartHome

AI 기반 에너지 고효율 스마트홈 시스템 실증사업을 소개하고 실증 참여 세대를 모집하기 위한 GitHub Pages 웹사이트입니다.

## GitHub Pages 게시 설정

1. 저장소의 `Settings` 메뉴로 이동합니다.
2. 왼쪽 메뉴에서 `Pages`를 선택합니다.
3. `Source`에서 `Deploy from a branch`를 선택합니다.
4. 브랜치는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.

## 게시 전 확인

- 공식 사업명과 주무부처 표기
- 모집 단지, 모집 기간과 대상 조건
- 설치 품목과 작업 시간
- 개인정보 수집·이용·보관·파기 및 참여 철회 절차
- 참여 혜택의 지급 시점, 소유권, 중도 철회 조건
- 참여기관 로고·제품 이미지 사용 승인
