# AI 스마트홈 GitHub Pages v5

이번 버전은 v4의 PC 디자인을 유지하면서 모바일 사용성을 추가 개선한 버전입니다.

## 주요 변경사항

### 1. 모바일 상단 바로가기 메뉴
스마트폰 화면에서 로고 아래에 다음 메뉴가 가로 스크롤 형태로 항상 표시됩니다.

- 핵심 정보
- 달라지는 점
- 설치 안내
- 작동 방식
- 진행 절차
- 데이터 보호
- FAQ
- 참여 문의

현재 보고 있는 섹션은 자동으로 강조되고, 해당 탭도 화면 안으로 자동 이동합니다.

### 2. AI 스마트홈 작동 방식
모바일에서 가로 스와이프를 제거했습니다.
`센서·사용자 입력 → 통합 조절기/앱 → 냉·난방·환기·공기청정`의 전체 흐름이 휴대폰 화면 너비 안에서 한 번에 보이도록 축소·재배치했습니다.

### 3. 기존 모바일 스와이프 유지 영역
다음 영역은 카드가 많으므로 좌우 스와이프 방식을 유지합니다.

- 실증 핵심 정보
- 연구기관
- 실증 협조기관
- 설치 항목
- 실증 진행 절차
- 데이터 항목

FAQ는 기존 아코디언 방식을 유지합니다.

## GitHub Pages 업데이트 방법
현재 v4를 사용하고 있다면 다음 3개 파일을 교체하면 됩니다.

- index.html
- style.css
- script.js

assets 폴더는 변경하지 않았습니다.
변경이 바로 보이지 않으면 Windows 기준 Ctrl + F5로 강력 새로고침하세요.
